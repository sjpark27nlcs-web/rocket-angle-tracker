Rocket Angle Tracker

Logs phone orientation data for two-phone rocket triangulation. The primary line-of-sight calculation uses fixed gamma to reduce high-elevation Euler-angle discontinuities.

gamma_fixed_deg = -90 raw alpha/beta/gamma are debug only single-file HTML

1. Observer setup

If your phone's long body is parallel to the tracker barrel and the top of the phone points toward the front sight, use +Y. If the bottom of the phone points toward the front sight, use -Y.

6. Instructions

  1. Open this page directly in Safari/Chrome over HTTPS.
  2. Select the correct barrel-axis mode.
  3. Tap Enable Sensors.
  4. Point the sight at the launch pad and tap Calibrate.
  5. Tap Start Logging before launch.
  6. Track the rocket/parachute. Tap markers if possible.
  7. Download CSV and import it into MATLAB.

Use los_azimuth_deg / los_elevation_deg or los_az_delta_deg / los_el_delta_deg for MATLAB processing, not raw alpha/beta.
